The timeline is a visual summary of all the tool items you have used to change the media. It shows the location and duration of every tool item and can be used to easily select and move each of them.

Timeline tracks

Organize tool items on tracks

Timeline tracks act as separate layers that can help organize your tool items. When you create a new overlay, it has one track by default. Use “+ New Track” to add another.

{% include "core/user_guide/partials/screenshot.html" with caption="Track 1, Track 2, and “+ New Track”" wide=True %}

Edit tool items on the timeline

Each tool item is represented in the timeline by a colored block labeled with the item’s name.

  1. Select an item

    Click its block. Its settings appear in the Properties Panel under the matching name.

    {% include "core/user_guide/partials/screenshot.html" with caption="Selected timeline block" wide=True %}

  2. Change its Start and End Times

    Click and drag the handles on either end of the colored block.

    {% include "core/user_guide/partials/screenshot.html" with caption="Dragging a block handle" wide=True %}

  3. Move it

    Click anywhere between the handles and drag it to another location on the timeline, or onto another track.

    {% include "core/user_guide/partials/screenshot.html" with caption="Dragging a block to another track" wide=True %}

Timeline Scrub Head

Find your place in the video

The Scrub Head on the timeline is synced with the Scrub Head on the Overlay Preview controls. Both indicate the current location of the video. For the exact location, refer to the Timecode.

{% include "core/user_guide/partials/screenshot.html" with caption="Timeline Scrub Head" wide=True %}

Zoom and scroll

  1. Zoom in for precise adjustments

    Timeline Zoom increases the length of the timeline so tool items appear longer.

    {% include "core/user_guide/partials/screenshot.html" with caption="Timeline Zoom control" wide=True %}

  2. Scroll to see the rest of the timeline

    When zoomed in, click and drag the Timeline Scroll Bar to reach parts of the timeline beyond the visible area.

    {% include "core/user_guide/partials/screenshot.html" with caption="Timeline Scroll Bar" wide=True %}
