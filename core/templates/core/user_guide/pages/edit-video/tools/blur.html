The Blur tool adds a rectangular area where the visuals will be blurred. The position and size of the blur can be adjusted using the Blur Area on the Overlay Preview and the Anchor Points under the Properties Panel.

Add a Blur item Adjust the Blur Area Anchor Points Animate the Blur Area

Add a Blur item

  1. Move the Scrub Head to where the edit should start

    The new tool item’s Start Time defaults to the timecode where the Scrub Head is located.

    {% include "core/user_guide/partials/screenshot.html" with caption="Scrub Head on the timeline" wide=True %}

  2. Click (+) next to Blur

    The (+) button is to the right of the tool in the Overlay Tool Selection Panel. A colored block appears on the timeline.

    {% include "core/user_guide/partials/screenshot.html" with caption="Blur row in the Tool Selection Panel" %}

  3. Set the Start and End Times

    Drag the handles on either end of the timeline block, or type the timecodes in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Blur item Start and End fields" %}

Adjust the Blur Area

The Blur Area appears in the Overlay Preview, directly on the video, so you can see exactly where the blur will appear.

  1. Resize the area

    Click and drag the handles (the large white dots on the corners and sides of the area). For more precision, use the W and H fields in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Blur Area with resize handles" wide=True %}

  2. Move the area

    Click inside the boundary (indicated by the dotted line) and drag it to the desired position. For more precision, use the X and Y fields in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Blur Area being dragged" wide=True %}

Anchor Points

What an Anchor Point is

An Anchor Point is a moment on the timeline where the position and size of the Blur Area is saved. Other media editors commonly refer to this as a “keyframe.”

  • Time indicates where in the timeline the blurred area appears.
  • X and Y indicate the Blur Area’s relative position.
  • W indicates the Blur Area’s width and H is its relative height.

The X, Y, W, and H properties use percentages compared to the size of the original video.

{% include "core/user_guide/partials/screenshot.html" with caption="Anchor Point fields: Time, X, Y, W, H" wide=True %}

Animate the Blur Area

You can animate the Blur Area to follow a moving subject. Set anchor points to define its position and size at different times. During playback, the Blur Area moves and resizes between the anchor points.

  1. Add a Blur item and set its starting position

    Adjust its Start Time. Set the blur’s initial position and size using the Blur Area in the Overlay Preview or with the Anchor Point 1 fields in the Properties Panel. Anchor Point 1 is created by default.

    {% include "core/user_guide/partials/screenshot.html" with caption="Anchor Point 1 fields" wide=True %}

  2. Set the End Time

    Use the Properties Panel, or adjust the item’s handles on the timeline.

    {% include "core/user_guide/partials/screenshot.html" with caption="Blur item handles on the timeline" wide=True %}

  3. Add more anchor points

    Move the Scrub Head to a point between the Start Time and the End Time. Move or resize the Blur Area in the Overlay Preview to add an anchor point at that time. Repeat as needed.

    {% include "core/user_guide/partials/screenshot.html" with caption="Blur Area repositioned at a later time" wide=True %}

  4. Delete an anchor point (optional)

    Click one of its value fields in the Properties Panel, then click the trash icon to the right of those fields.

    {% include "core/user_guide/partials/screenshot.html" with caption="Anchor Point trash icon" %}
