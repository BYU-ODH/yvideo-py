The Clip tool lets you show only specific portions of the full video, determined by the Start and End times of each Clip tool item you use.

Add a Clip item Clip options

Add a Clip item

  1. Move the Scrub Head to where the edit should start

    The new tool item’s Start Time defaults to the timecode where the Scrub Head is located.

    {% include "core/user_guide/partials/screenshot.html" with caption="Scrub Head on the timeline" wide=True %}

  2. Click (+) next to Clip

    The (+) button is to the right of the tool in the Overlay Tool Selection Panel. A colored block appears on the timeline.

    {% include "core/user_guide/partials/screenshot.html" with caption="Clip row in the Tool Selection Panel" %}

  3. Set the Start and End Times

    Drag the handles on either end of the timeline block, or type the timecodes in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Clip item Start and End fields" %}

Clip options

Clips Only

On the details page of the overlay, you can select “Clips Only,” which forces the Student Media Player to show only the clips you have selected.

{% include "core/user_guide/partials/screenshot.html" with caption="“Clips Only” option on the overlay details page" %}

View Previous / Next Clip

Navigate through multiple Clip tool items using the View Previous Clip and View Next Clip buttons.
