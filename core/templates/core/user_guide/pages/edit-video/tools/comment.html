The Comment tool adds custom text over the original video. How the text looks can also be adjusted to better fit the needs of the video.

Add a Comment item Adjust the Text Box Comment properties

Add a Comment item

  1. Move the Scrub Head to where the edit should start

    The new tool item’s Start Time defaults to the timecode where the Scrub Head is located.

    {% include "core/user_guide/partials/screenshot.html" with caption="Scrub Head on the timeline" wide=True %}

  2. Click (+) next to Comment

    The (+) button is to the right of the tool in the Overlay Tool Selection Panel. A colored block appears on the timeline.

    {% include "core/user_guide/partials/screenshot.html" with caption="Comment row in the Tool Selection Panel" %}

  3. Set the Start and End Times

    Drag the handles on either end of the timeline block, or type the timecodes in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Comment item Start and End fields" %}

Adjust the Text Box

The Text Box appears in the Overlay Preview, directly on the video. You can see exactly how the text will appear, with its size, color, and position.

  1. Resize the Text Box

    Click and drag the handles (the large white dots on the left and right sides of the text box). The height adjusts automatically to fit the text. For more precision, use the W field in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Text Box with side handles" wide=True %}

  2. Move the Text Box

    Click inside the boundary (indicated by the dotted line) and drag it to the desired position. For more precision, use the X and Y fields in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Text Box being dragged" wide=True %}

Comment properties

Comment Text

Any text that appears in the Comment Text section will appear in the Text Box on the Overlay Preview.

{% include "core/user_guide/partials/screenshot.html" with caption="Comment Text field" %}

Text Size

Type a number in the Text Size field, or click the up or down arrows that appear on the right side of the field when you hover over it.

{% include "core/user_guide/partials/screenshot.html" with caption="Text Size field" %}

Text Color (hex code)

Type any hex code into the Text Color field, or select one of the eight preset colors from the dropdown menu:

  • Black – #000000
  • White – #FFFFFF
  • Dark Gray – #333333
  • Blue
  • Red
  • Green
  • Orange
  • Yellow
{% include "core/user_guide/partials/review_note.html" with note="The hex codes for Blue, Red, Green, Orange, and Yellow could not be read in the source frame. Add them here." %} {% include "core/user_guide/partials/screenshot.html" with caption="Text Color field and preset dropdown" %}

Position & Size

X and Y indicate the Text Box’s relative position. W indicates its relative width. These properties use percentages compared to the size of the original video. The height of the text box is adjusted automatically to fit the text.
