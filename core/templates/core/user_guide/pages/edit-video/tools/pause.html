The Pause tool stops the video on the frame indicated by the Start Time. Pressing play resumes the video from that frame.

Add a Pause item

  1. Move the Scrub Head to where the edit should start

    The new tool item’s Start Time defaults to the timecode where the Scrub Head is located.

    {% include "core/user_guide/partials/screenshot.html" with caption="Scrub Head on the timeline" wide=True %}

  2. Click (+) next to Pause

    The (+) button is to the right of the tool in the Overlay Tool Selection Panel. A colored block appears on the timeline.

    {% include "core/user_guide/partials/screenshot.html" with caption="Pause row in the Tool Selection Panel" %}

  3. Set the Start and End Times

    Drag the handles on either end of the timeline block, or type the timecodes in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Pause item Start and End fields" %}
