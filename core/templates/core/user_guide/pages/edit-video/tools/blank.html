The Blank tool replaces the video image between the Start and End times with the selected Blank Type while leaving any audio unedited.

Add a Blank item Blank properties

Add a Blank item

  1. Move the Scrub Head to where the edit should start

    The new tool item’s Start Time defaults to the timecode where the Scrub Head is located.

    {% include "core/user_guide/partials/screenshot.html" with caption="Scrub Head on the timeline" wide=True %}

  2. Click (+) next to Blank

    The (+) button is to the right of the tool in the Overlay Tool Selection Panel. A colored block appears on the timeline.

    {% include "core/user_guide/partials/screenshot.html" with caption="Blank row in the Tool Selection Panel" %}

  3. Set the Start and End Times

    Drag the handles on either end of the timeline block, or type the timecodes in the Properties Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Blank item Start and End fields" %}

Blank properties

Blank Type

You can select one of three options when replacing the visuals:

  • Black displays a solid black screen
  • White displays a solid white screen
  • Blur obscures the original content by blurring it
