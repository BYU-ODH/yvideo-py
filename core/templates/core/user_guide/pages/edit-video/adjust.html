When you select a tool item on the timeline, the right panel displays properties that can be adjusted to modify how that item affects the media. Every tool item has Undo/Redo buttons, a Delete button, a name, Start and End Times, and a Description.

Make sure the name at the top of the Properties Panel matches the name on the timeline block, so you are editing the correct tool item.

Common properties

Overlay Tool Name

The bold label at the top of the Properties Panel shows what kind of tool you have selected. This tells you what it will do to the video and which properties can be adjusted.

{% include "core/user_guide/partials/screenshot.html" with caption="“Edit Mute” label at top of Properties Panel" %}

Undo & Redo

Select a tool item on the timeline, then select Undo or Redo at the top of the Properties Panel. These controls apply only to the selected item, so they may not reverse the last change you made to a different item.

For example, if you edit a Comment item, then add a Mute item, but want to undo the Comment edit, you must select that Comment item before clicking Undo.

{% include "core/user_guide/partials/screenshot.html" with caption="Undo, Redo, and Delete icons" %}

Delete

Click the trash icon to delete the selected tool item.

Deleting an item is permanent and cannot be undone.

{% include "core/user_guide/partials/screenshot.html" with caption="Delete icon" %}

Tool Item Name

Type a new name into the text field and press Enter on the keyboard.

{% include "core/user_guide/partials/screenshot.html" with caption="Name field" %}

Start and End Times

These show where the item appears on the timeline and for how long. To change them, type the timecode into the respective field.

{% include "core/user_guide/partials/screenshot.html" with caption="Start and End fields" %}

Item Description

Leave notes to yourself about the item. Descriptions do not appear on the published video or affect the item in any other way.
