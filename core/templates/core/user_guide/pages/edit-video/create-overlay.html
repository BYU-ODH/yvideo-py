An overlay is a set of edits applied on top of an original resource video. You can create several overlays for the same video, for example one per course, and name each one so you can tell them apart.

Create a new overlay Rename an overlay

Create a new overlay

  1. Select a video

    In the desired playlist, select the video you want to edit.

    {% include "core/user_guide/partials/screenshot.html" with caption="Video in a playlist" wide=True %}

  2. Select Edit Video

    Near the top of the page, select Edit Video. When you want to return to the Overlay Editor to continue work on this edit, follow the same steps.

    {% include "core/user_guide/partials/screenshot.html" with caption="“Edit Video” button" %}

  3. Name the overlay

    You will be asked to name that specific overlay. This will help differentiate it from other edits that use the same original resource.

    {% include "core/user_guide/partials/review_note.html" with note="Step 3 is blank in the latest edits. This is the previous step 3, kept until the new text is written." %} {% include "core/user_guide/partials/screenshot.html" with caption="Overlay name prompt" %}

Rename an overlay

The name you assign appears at the top left of the editor and can be changed at any time.

  1. Click the pen icon next to the name

    The pen icon is to the right of the overlay name, at the top of the Overlay Tool Selection Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="Overlay Name with pen and three-dot icons" %}

  2. Type the new name and press Enter

    Once you have typed in a new name, use the Enter key to confirm it.

    {% include "core/user_guide/partials/screenshot.html" with caption="Overlay Name field in edit mode" %}
