Add a tool item View a tool’s items Delete a tool item

Add a tool item

  1. Move the Scrub Head to where the edit should start

    The Start Time of a newly created tool item defaults to the timecode where the Scrub Head is located.

    {% include "core/user_guide/partials/screenshot.html" with caption="Scrub Head on the timeline" wide=True %}

  2. Click (+) to the right of the tool you want to add

    The new item appears in the panel and as a colored block on the timeline.

    {% include "core/user_guide/partials/screenshot.html" with caption="Skip row with (+) button" %}

View a tool’s items

  1. Click the caret to the left of the tool

    A list of every item for that tool in the current media appears below it.

    {% include "core/user_guide/partials/screenshot.html" with caption="Mute expanded showing “Mute 1”" %}

Delete a tool item

  1. Select the tool item

    Select it from the list in the Selection Panel, or click its colored block on the timeline.

    {% include "core/user_guide/partials/screenshot.html" with caption="Selected tool item in the panel and timeline" wide=True %}

  2. Click the trash icon

    The trash icon appears in the Selection Panel and in the Properties Panel.

    Deleting an item is permanent and cannot be undone.

    {% include "core/user_guide/partials/screenshot.html" with caption="Trash icon on a tool item" %}
