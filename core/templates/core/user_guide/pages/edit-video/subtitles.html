Open the Subtitle Editor

  1. Click “Switch to Subtitle Editor”

    The button is at the bottom of the Overlay Tools panel. It replaces the Overlay Tools panel with the Subtitle Editor Panel.

    {% include "core/user_guide/partials/screenshot.html" with caption="“Switch to Subtitle Editor” button" %}

Select or create a subtitle track

  1. Click the three dots at the top right of the Subtitle Editor panel

    This opens the Subtitles Settings window.

    {% include "core/user_guide/partials/screenshot.html" with caption="Subtitles Settings window" %}

  2. Select a track from the dropdown

    The default subtitle tracks include any tracks extracted from the original resource.

    {% include "core/user_guide/partials/screenshot.html" with caption="“Select a subtitles track” dropdown" %}

  3. Or click “+ Add new subtitle track”

    Creates a new, empty track.

    {% include "core/user_guide/partials/screenshot.html" with caption="“+ Add new subtitle track” button" %}

  4. To remove a track, click “Delete subtitle track”

    This removes the selected track from the available options when published.

    {% include "core/user_guide/partials/screenshot.html" with caption="“Delete subtitle track” button" %}

Edit subtitles

Edit timing

Next to each subtitle text block are two timestamps that indicate the location and duration of the subtitle on the timeline. The top is the Start Time, the bottom is the End Time.

{% include "core/user_guide/partials/review_note.html" with note="The original sentence ended “…of the subtitle on the .” Confirm “timeline” is the intended word." %} {% include "core/user_guide/partials/screenshot.html" with caption="Subtitle row with Start and End timestamps" %}

Edit text

Adjust the text by typing in the text field.

{% include "core/user_guide/partials/screenshot.html" with caption="Subtitle text field" %}

Add a new subtitle

Clicking “+ Add new subtitle at current time” creates a new section.

{% include "core/user_guide/partials/review_note.html" with note="+++ flagged in the original guide. Confirm where the new subtitle is placed and its default duration." %} {% include "core/user_guide/partials/screenshot.html" with caption="“+ Add new subtitle at current time” button" %}

Return to the Overlay Tools

Switch back to the Overlay Tools panel by clicking the button at the bottom of the Subtitle Editor.
