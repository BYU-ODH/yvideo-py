An overlay is a set of edits applied on top of an original resource video. You can create several overlays for the same video, for example one per course, and name each one so you can tell them apart.

Create a new overlay

  1. Open the video’s details page

    Go to Your Videos and select the original resource you want to edit. The details page shows the video, its description, and the overlays already made from it.

    {% include "core/user_guide/partials/screenshot.html" with caption="Original Resource Video details page" wide=True %}

  2. Select “Edit Video,” then “Create New Overlay”

    On the newer details page this button appears as “+ Add New Overlay,” next to “Your Overlays of [video title].”

    {% include "core/user_guide/partials/review_note.html" with note="The original guide says “Edit Video” > “Create New Overlay.” The current designs show “+ Add New Overlay.” Confirm which label is live." %} {% include "core/user_guide/partials/screenshot.html" with caption="“+ Add New Overlay” button on the details page" %}

  3. Name the overlay

    You will be asked to name that specific overlay. This will help differentiate it from other edits that use the same original resource.
