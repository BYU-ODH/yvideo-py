Playlist details

Title and description

Click the pen icon next to the playlist title to rename it. Edit the description below the title.

{% include "core/user_guide/partials/screenshot.html" with caption="Playlist title and description" wide=True %}

Change Thumbnail

Select “Change Thumbnail” to choose the image shown on the playlist card.

{% include "core/user_guide/partials/screenshot.html" with caption="“Change Thumbnail” button" %}

Duplicate

Select “Duplicate” to make a copy of the playlist, for example to reuse it in a new semester.

{% include "core/user_guide/partials/screenshot.html" with caption="“Duplicate” button" %}

Video descriptions in a playlist

Each video in the playlist has a description. It defaults to the overlay’s description but can be edited here without changing the overlay.

{% include "core/user_guide/partials/screenshot.html" with caption="Video row with editable description" wide=True %}

Video details

These settings are on the Original Resource Video page.

Make Available To Faculty

Turn this toggle on to let other faculty find and use the video.

{% include "core/user_guide/partials/screenshot.html" with caption="“Make Available To Faculty” toggle" %}

Available Languages

Choose the languages available for the video from the dropdown.

{% include "core/user_guide/partials/screenshot.html" with caption="Available Languages dropdown" %}

Renew Permission

Each video has an Approve Date and an Expire Date. Select “Renew Permission” to request an extension before the video expires.
