Create a playlist

  1. Go to Your Playlists

    Select Playlists in the top navigation bar. Your Playlists lists every playlist you own, with its visibility and number of videos.

    {% include "core/user_guide/partials/review_note.html" with note="Will there be a separate home page, or is My Playlists the home page?" %} {% include "core/user_guide/partials/screenshot.html" with caption="Your Playlists page" wide=True %}

  2. Select “+ Create New Playlist”

    A new, empty playlist opens.

    {% include "core/user_guide/partials/screenshot.html" with caption="“+ Create New Playlist” button" %}

  3. Name the playlist

    When you create a new playlist, you must assign it a name. This name is what it will appear as to your students.

    {% include "core/user_guide/partials/screenshot.html" with caption="Playlist name field" %}

  4. Assign the playlist’s thumbnail

    By default, the thumbnail will be assigned a solid color background with white text. You can customize the background color or upload your own image. You can also adjust the text that appears, as well as its color and size.

    {% include "core/user_guide/partials/screenshot.html" with caption="Thumbnail editor" wide=True %}
