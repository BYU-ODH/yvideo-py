Create a playlist

  1. Go to Your Playlists

    Select Playlists in the top navigation bar. Your Playlists lists every playlist you own, with its visibility and number of videos.

    {% include "core/user_guide/partials/screenshot.html" with caption="Your Playlists page" wide=True %}

  2. Select “+ Create New Playlist”

    A new, empty playlist opens.

    {% include "core/user_guide/partials/screenshot.html" with caption="“+ Create New Playlist” button" %}

  3. Name the playlist and add a description

    Click the pen icon next to the playlist title to rename it, then add a brief description of the playlist and its contents.

    {% include "core/user_guide/partials/screenshot.html" with caption="Playlist title with pen icon and description" wide=True %}

  4. Select “Save Changes”

    The Save Changes button is at the bottom of the playlist page.

    {% include "core/user_guide/partials/screenshot.html" with caption="“Save Changes” button" %}
