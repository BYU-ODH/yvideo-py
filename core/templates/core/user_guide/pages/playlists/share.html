Add individual viewers

Viewers can watch the playlist but cannot change it.

  1. Under Publishing Details, select “+ Add People” next to Individuals

    Use this for people outside the courses you have published to.

    {% include "core/user_guide/partials/screenshot.html" with caption="Individuals “+ Add People”" %}

  2. Enter their name or email and save

    Select “Save Changes” to give them access.

    {% include "core/user_guide/partials/screenshot.html" with caption="Add People form" %}

Add collaborators

Collaborators can edit the playlist.

  1. In the Collaborators panel, select “+ Add People”

    The panel lists each collaborator’s name and email.

    {% include "core/user_guide/partials/screenshot.html" with caption="Collaborators panel" wide=True %}

  2. Enter their name or email and save

    Select “Save Changes.”

    {% include "core/user_guide/partials/screenshot.html" with caption="Add collaborator form" %}

  3. To remove someone, select the trash icon on their row

    This works the same way for individual viewers and collaborators.

    {% include "core/user_guide/partials/screenshot.html" with caption="Collaborator row trash icon" %}
