Add courses and individuals

  1. Select Playlist

    Select the playlist you want to publish to your students.

    {% include "core/user_guide/partials/screenshot.html" with caption="Playlist page" wide=True %}

  2. Find Publishing Details

    Find the Publishing Details to the right of the list of videos. This lists everyone who can view the playlist.

    {% include "core/user_guide/partials/screenshot.html" with caption="Publishing Details panel" wide=True %}

  3. Add a course and its sections

    Select Add Course. A modal will appear where you can select the semester from a dropdown. Once a semester is selected, you can search for the course. Enter the sections that should see the playlist. If no sections are entered, it will default to all of them.

    {% include "core/user_guide/partials/screenshot.html" with caption="Add Course modal" wide=True %}

Remove courses or individuals

  1. Select the trash icon on the course row

    Students in that course will no longer see the playlist after you save.
