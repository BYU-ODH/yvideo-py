Publish to a course

  1. Find Publishing Details on the playlist page

    The Publishing Details panel lists everyone who can view the playlist.

    {% include "core/user_guide/partials/screenshot.html" with caption="Publishing Details panel" wide=True %}

  2. Choose the semester

    Select the semester from the Semester dropdown, for example Fall 2025.

    {% include "core/user_guide/partials/screenshot.html" with caption="Semester dropdown" %}

  3. Add a course and its sections

    Select “+ Add Course,” choose the course from the dropdown, then enter the sections that should see the playlist. Repeat for each course.

    {% include "core/user_guide/partials/screenshot.html" with caption="Course row with sections" wide=True %}

  4. Choose which videos are published

    Use the toggle on each video to switch it between Published and Unpublished. Unpublished videos stay in the playlist but students cannot see them.

    {% include "core/user_guide/partials/screenshot.html" with caption="Published / Unpublished toggle on a video row" %}

  5. Publish and save

    Select “Publish,” then “Save Changes.” The button changes to “Unpublish” once the playlist is live.

    {% include "core/user_guide/partials/screenshot.html" with caption="Publish / Unpublish button" %}

Remove a course

  1. Select the trash icon on the course row

    Students in that course will no longer see the playlist after you save.

    {% include "core/user_guide/partials/screenshot.html" with caption="Course row trash icon" %}
