Add a video to a playlist

  1. Select a playlist

    Open the playlist page where you want the new video to be shared.

    {% include "core/user_guide/partials/screenshot.html" with caption="Playlist page" wide=True %}

  2. Select Add New Video

    Click the Add New Video button.

    {% include "core/user_guide/partials/screenshot.html" with caption="“Add New Video” button" %}

  3. Choose a source for the video

    After you select Add New Video, choose where the video comes from.

    A video already in Y Video

    1. Select Create from existing resource.
    2. Search for the video, then select it from the list.
    3. Enter a title and select the version you want to use.
    4. Select Create.

    A YouTube video

    1. Enter a name for the video in the Title field.
    2. Paste the video’s link into the YouTube URL field.
    3. Select Add YouTube Video.

    A video that isn’t in Y Video yet

    1. Select Request a new resource.
    2. Search for the video by title or BYU barcode, then select Search to make sure it isn’t already in Y Video.
    3. If no results appear, complete the request form and follow the instructions.
    4. You will be notified when the video is ready. You can then add it using Create from existing resource.
    {% include "core/user_guide/partials/screenshot.html" with caption="Add New Video dialog" wide=True %}

  4. Customize the thumbnail

    Background

    • Solid color: Choose one of seven colors.
    • Video frame (Y Video resources only): Drag the slider below the preview to choose a frame. Use the arrows on either side of the slider for finer control.
    • YouTube (YouTube videos only): Use the video’s thumbnail from YouTube.
    • Upload: Upload your own image ([ACCEPTED FILE TYPES AND SIZE LIMIT]).

    Text

    • Text: Enter the text to show on the thumbnail. Leave it blank for no text.
    • Color: Choose white text with a black shadow or black text with a white shadow.
    • Size: Drag the slider to change the text size.
