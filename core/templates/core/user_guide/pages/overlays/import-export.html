Import an overlay from a JSON file

{% include "core/user_guide/partials/review_note.html" with note="Placeholder content drafted from the current app designs. The original guide describes exporting but not importing." %}

  1. Open the original resource the overlay was made for

    Imported overlays apply to the same original resource they were exported from.

    {% include "core/user_guide/partials/screenshot.html" with caption="Original Resource Video page" wide=True %}

  2. Choose the import option

    Select the import option and choose the JSON file.

    {% include "core/user_guide/partials/screenshot.html" with caption="Import option" %}

  3. Review and rename the imported overlay

    The imported overlay opens in the editor. Rename it so it is easy to tell apart.

    {% include "core/user_guide/partials/screenshot.html" with caption="Imported overlay in the editor" wide=True %}

Overlay Settings menu

Clicking the three dots to the right of the overlay name opens a menu that lets you export, change, or retire the overlay you have open.

Open the menu

Click the three dots to the right of the overlay name.

{% include "core/user_guide/partials/screenshot.html" with caption="Overlay Settings menu" %}

Export Overlay

Export the selected overlay as a JSON file that others can import and use for their resources.

{% include "core/user_guide/partials/screenshot.html" with caption="“Export Overlay” menu item" %}

Change Overlay

Select from a list of overlays that you or others have used to edit the same original resource. The editor updates to match the selected overlay.

{% include "core/user_guide/partials/screenshot.html" with caption="“Change Overlay” list" %}
