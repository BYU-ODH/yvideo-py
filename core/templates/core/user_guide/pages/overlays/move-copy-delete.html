Overlays Playlists and videos

Overlays

On Your Videos, select an overlay to see its Publishing Details and actions.

Edit, Move, or Copy

Edit opens the overlay in the editor. Move and Copy place the overlay in a different playlist.

{% include "core/user_guide/partials/screenshot.html" with caption="Overlay card with Edit, Move, Copy, Delete" wide=True %}

Delete an overlay

Select Delete. Students in any playlist that uses this overlay will lose access to it.

{% include "core/user_guide/partials/screenshot.html" with caption="Overlay Delete button" %}

Unpublish All

On the Original Resource Video page, “Unpublish All” hides every overlay of that video from students without deleting them.

{% include "core/user_guide/partials/screenshot.html" with caption="“Unpublish All” button" %}

Playlists and videos

Archive a playlist

Select “Archive” on the playlist page. Archived playlists move to the Archive section on Home, where you can restore them later.

{% include "core/user_guide/partials/screenshot.html" with caption="Playlist “Archive” button and Home Archive card" wide=True %}

Delete a playlist

Select “Delete” on the playlist page.

{% include "core/user_guide/partials/screenshot.html" with caption="Playlist “Delete” button" %}

Delete a video

Select “Delete” on the Original Resource Video page.
