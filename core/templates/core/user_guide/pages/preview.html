View how your edits will affect the video by using the Overlay Preview. This control window contains all the normal functions found in other common media players, as well as two additional tools.

Play a single clip

  1. Click the scissors icon

    A menu opens with all the sections of the media you have selected using the Clip tool.

    {% include "core/user_guide/partials/screenshot.html" with caption="Clip Select menu" %}

  2. Select a clip

    That portion of the timeline is highlighted in yellow and the Scrub Head moves to its Start Time. The Overlay Preview plays the section and stops at the End Time set in that clip’s properties.

    {% include "core/user_guide/partials/screenshot.html" with caption="Timeline with clip highlighted in yellow" wide=True %}

Read the subtitle transcript

  1. Click the Subtitle Transcript button

    A panel opens to the right of the Overlay Preview window listing the transcript of all the subtitles.
