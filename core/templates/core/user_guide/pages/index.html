What’s this for?

{% include "core/user_guide/partials/review_note.html" with note="CHANGE THIS +++ (placeholder note from the original guide)" %}

The Overlay Editor is where you can edit video content to suit the needs of your students. The editor provides seven simple tools for you to modify your media: Skip, Mute, Blank, Pause, Blur, Comment, and Clip.

These tools are nondestructive, meaning they will not directly modify the video itself. Copyright laws prohibit users from actually editing the original video file. Instead, the editor creates an overlay that modifies how the media player shows the video. For example, the “Skip” tool does not remove the selected section of the video, it instead instructs the media player to automatically jump over that section. So, while the original video is left unedited, the overlay you publish will show whatever you have modified.
