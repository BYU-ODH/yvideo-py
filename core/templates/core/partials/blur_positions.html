{% comment %} The method, not the mechanism. A blur always arrives with a box already on the frame, so there is nothing to create and nothing to add - the user only ever moves the one that is there. Saying so is what stops "blur point" being read as "another blur". The procedure for a moving target is bisection, and it is worth spelling out because it converges fast and is not obvious: the worst error after two points is always somewhere in between, so fixing the worst spot repeatedly is the shortest route to a blur that tracks. {% endcomment %}

Drag the blur on the video to move it, or its handles to resize it. For moving targets, adjust the blur at the beginning, then adjust the blur at the end, then repeatedly find where the blur is farthest from the target and adjust its position there.

It is also the only part of this wrapper that a save replaces - the help text above and the status line below survive, which is what lets that status line work as a live region at all.
