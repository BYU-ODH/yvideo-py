{% comment %} `available_annotation_sets` is a list of dicts from annotation_set_choices(): every set on this resource the user may read, each marked with whether they may edit it. `selector_id` is required: the editor renders this partial three times on one page (export, copy-from and use-existing), so a hard-coded id would repeat, and the label would point at whichever select happened to be first. JS finds these by .annotation-set-selector, not by id. {% endcomment %}

Selecting a set points your video at it rather than copying it. If someone else owns it, they may change it, and any changes they make will show up here. If you own it, other classes may be using it, so your edits will show up for them too.
