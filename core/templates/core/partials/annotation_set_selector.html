What is a retired annotation set?

A retired annotation set is not editable but may be used. If you end up needing to make a change to it, you must make a copy of it and make your changes there.

Selecting a set points your video at it rather than copying it. If someone else owns it, they may change it, and any changes they make will show up here. If you own it, other classes may be using it, so your edits will show up for them too.
