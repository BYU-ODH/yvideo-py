What's new in Y-Video

If you taught with the previous version of Y-Video, most of what you know still applies. A few things were renamed, and a few things you used to work around are now built in. Here is what changed.

Collections are now ‘Playlists’

What you built as a collection is called a playlist now. Nothing about how you use it changed: it is still the shelf you put media on and hand to a class.

Annotation sets are shareable

The edits you make to a film are stored in an annotation set, and that set is no longer locked to one piece of content. An annotation set is linked to the underlying media, so the same set can be used by any content built from that media — yours or a colleague's.

When you open the editor you can:

  • Create a new, empty set.
  • Use an existing set that you or someone else already made for this media. All future changes to this annotation set are automatically applied to your content.
  • Copy from an existing set when you want your own version to diverge from theirs.
  • Import a set from a file, and export one to hand off.

One editor to rule them all

The three editors in the old Y-video (video editor, clip editor, and subtitle editor) are now combined into one. Each annotation type is color-coded and can be grouped in custom tracks in the timeline. Annotation edits save as you make them and can be undone and redone, either with the toolbar buttons or with Ctrl+Z and Ctrl+Shift+Z.

Safer options for Fair Use

You can now limit playback to clips that you specify, which has much stronger protection for Fair Use's definitions of "reasonable or limited amount" or "short portions" of a work.

Bringing your old collections over

Your work in the previous Y-Video is not gone. You can request that a collection be migrated into this system, and it will arrive as a playlist with its content, annotations, and access list intact.

Open Legacy Migration Requests and submit the address or ID of the collection in the old system. An administrator reviews the request and runs the migration. You will be able to see the status of anything you have requested on that same page.

Still stuck?

If something you relied on seems to be missing, it is worth asking! We are actively developing the new system and we can probably implement your requests relatively quickly. Let us know what you think here!
