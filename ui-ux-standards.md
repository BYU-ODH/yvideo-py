# UI UX Standards for Y-Video

## Renaming/titling a model instance
Standard: In-line edit\
Example: Renaming an annotation set\
Simple display text changes should be handled in line with the display text presented on the left and
an edit button shown on the right.

## Infrequent Extensive model instance edits
Standard: Modal edit\
Example: Change subtitle track name, language, and other data
If a model instance needs to be edited beyond it's display text and it is expected that the instance
will be edited infrequently, all editable fields should be presented in a modal using the standard
modal UI.

## Frequent Extensive model instance edits
Standard: Reserved space on main view
Example: Editing an annotation instance
Instances that need to be extensively edited frequently should have their own reserved space in
the view they are pertinent to.
